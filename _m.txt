Remove duplicated hamburger-menu CSS from franchise homepages

fix_dropdown_backgrounds() in build_statedoc_site.py injected its 788-line
block at the last </style> on every build with no idempotency check, while
convert_categories_to_collapsible() twenty lines above it has always had that
guard. Copies therefore accumulated one per deploy, reaching six on every
homepage and seven on Nebraska.

That was 3.41 MB of duplicated CSS across the 29 homepages, 22.8% of their
total weight, growing 715 KB per deploy. Every copy is byte-identical so only
the first ever applied; the rest were pure page weight on the pages being
tuned for Core Web Vitals.

Deduped to one copy each: 15.41 MB -> 11.99 MB. Verified per file that the
delimiters were a clean 1:1 set of complete blocks, that all copies were
identical before removing any, and afterwards that each page still has exactly
one copy, its canonical, its closing tags and its CTAs. The .nav-links and
.mobile-menu-toggle rules still resolve, so the nav is unchanged.

The guard is added in the ODECON repo in the same change, so this cannot
regrow.
